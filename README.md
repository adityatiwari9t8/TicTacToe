# Tic Tac Toe Pro

A simple and polished browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## 🚀 Live Preview
Open `index.html` in your browser (double-click or serve a local web server).

## 🎮 Game Features
- 3x3 interactive game board
- X and O players with turn indicator
- Win detection for all rows, columns, and diagonals
- Draw detection after 9 filled squares
- Scoreboard (X wins, O wins, Draws)
- Reset board / New game button
- Visual win highlight + overlay message
- Clean responsive UI with animated effects

## 🧩 File Structure
- `index.html`: Game UI and structure
- `style.css`: Visual style, animations, responsive layout
- `app.js`: Game logic and state management

## 🛠️ Setup (Local Development)
1. Clone the repository
   ```bash
   git clone <repo-url> TicTacToe
   cd TicTacToe
   ```
2. Open `index.html` in your browser or run a local server
   - Quick option (Python 3):
     ```bash
     python3 -m http.server 5500
     ```
   - Visit `http://localhost:5500`

## ▶️ How to Play
1. Player X starts first.
2. Click any empty cell to place X or O.
3. First player with 3 in a row wins.
4. If all 9 cells fill with no winner, it's a draw.
5. Click "Reset Board" or "New Game" to start over.
